# Regex Log Extractor

A Python-based utility that demonstrates the power of Regular Expressions (`re`) for parsing complex text structures, isolating specific log components (such as subsystem modules and error codes), and aggregating operational statistics.

## Key Features
- **Regex Pattern Matching:** Uses precise regex groups to extract data enclosed in brackets.
- **Error Aggregation:** Automatically counts and groups failures per system module.
- **Production-Ready Structure:** Clean code style with docstrings and modular functions.

## Tech Stack
- Python 3.x
- Built-in modules: `re`, `pprint`
